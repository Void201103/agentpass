AgentPass

Soulbound attendance badges for Agent ID holders. Organizers create events; holders of an Agent ID claim one badge per event — free, gas only.

Please read: claiming requires an Agent ID. Claiming is free (gas only) and there are no promised returns. Every transaction must be reviewed and confirmed by you in your own wallet — AgentPass never asks for your seed phrase, private key, or pairing code, and never signs anything on your behalf.

AgentPass is an independent community project built for the Agent ID Hackathon. Source code: github.com/Void201103/agentpass. Agent ID registry: 0x60b9262456de011f7d15a54cdd8c48baaa8b022f (BNB Chain). Badges are soulbound ERC-721 tokens — they cannot be transferred or sold.
